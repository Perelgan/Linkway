# Linkway

Linkway — портативный VPN-клиент для Windows 10/11 x64 с интеграцией с **Peregar vpn Cabinet**. Войдите в кабинет прямо из приложения, чтобы загрузить серверы из активных VPN-подписок и подключиться.

Клиент использует Mihomo, поддерживает системный прокси и TUN, правила для приложений и доменов и Kill Switch в режиме TUN.

## Запуск

1. Скачайте `VPNDesktop-win-x64.zip`, распакуйте архив целиком и откройте `VPNDesktop.exe`. Для TUN запустите клиент от имени администратора. [Скачать релиз](https://github.com/Perelgan/Linkway/releases/latest)
2. Добавьте ключ или URL VPN-подписки во вкладке **Источники** либо войдите в Peregar vpn Cabinet через **Аккаунт**.
3. Выберите сервер во вкладке **Подключение** и нажмите кнопку подключения.

## Обновления

В **Настройки → Обновления** нажмите на нужный канал. Клиент покажет сохранённый список и обновит его с GitHub. Экспериментальный канал включает предварительные релизы. Выберите **Последняя версия** или конкретную сборку, отключите VPN и нажмите **Установить сборку**. [Все релизы](https://github.com/Perelgan/Linkway/releases)

При переходе с версии `1.3.1` или ниже скачайте архив вручную. В этих версиях для обновлений используется прежний адрес GitHub.

## Сборка

Требуются Windows, SDK .NET 10 и Go. Команды запускаются из корня репозитория.

```powershell
pwsh -File .\Source\build.ps1 -ReleaseArchive
dotnet run --project .\Source\RoutingTests -c Release
```

Готовый архив появится в `Source\dist\VPNDesktop-win-x64.zip`. Тег GitHub должен совпадать с версией сборки с добавлением префикса `v`.

### Нумерация релизов

- **Малые изменения** повышают третье число и выходят только в экспериментальном канале. От `1.3.3` следующий малый выпуск — `1.3.4-beta.1`. Повторная сборка того же выпуска — `1.3.4-beta.2`, следующее самостоятельное малое изменение — `1.3.5-beta.1`.
- **Средние обновления** повышают второе число и сбрасывают третье. Следующий пример — `1.4.0`. Проверенные малые изменения можно включить в этот выпуск.
- **Крупные обновления** повышают первое число и сбрасывают остальные. Следующий пример — `2.0.0`.

Средние и крупные обновления обычно выходят в стабильном канале. Если нужна обкатка, сначала выпускается бета, например `1.4.0-beta.1`, затем стабильная `1.4.0`. На GitHub все сборки с суффиксом `-beta.N` помечаются как предварительные (*pre-release*).
