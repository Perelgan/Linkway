# История изменений Linkway

## 1.3.3

- При выборе канала открывается сохранённый список сборок и обновляется с GitHub. Добавлен пункт «Последняя версия».

## 1.3.2

- Обновления загружаются из переименованного репозитория Perelgan/Linkway.

## 1.3.1

- VPN-клиент переименован в Linkway.

## 1.3.0

- В настройках обновлений можно выбрать и установить конкретную опубликованную сборку выбранного канала, в том числе более раннюю.

## 1.2.0

- Встроены адрес GitHub и выбор канала обновлений. Стабильный канал получает обычные релизы, экспериментальный также получает предварительные.

## 1.1.0

- Подписки из кабинета передают провайдеру стабильный идентификатор Windows-устройства, привязанный к домену. Сообщения об отказе HWID и о лимите устройств отображаются как ошибки обновления вместо серверов.

- Источники из кабинета показывают название каждого тарифа. Для добавленных по ссылке подписок без собственного названия используется заголовок провайдера, если он передан.
- Если список кабинета не содержит название тарифа, клиент запрашивает карточку нужной подписки через API нескольких тарифов, с поддержкой старого API. Внутренние номера больше не показываются вместо названия.

- В меню направления убраны подписи источников у серверов. Из категорий подписки доступна только «Недоступные сайты».

- В списках запущенных и установленных приложений показываются значки EXE.

- Имена серверов с эмодзи-флагом или двухбуквенным кодом страны отображаются с цветным флагом.

- Скрыты служебные группы подписки в интерфейсе. Правила подписки по-прежнему могут направлять трафик через эти группы.

- Удалены пользовательские резервные группы. Их маршруты в старых профилях заменяются первым сервером прежней группы.
- Добавлен Kill Switch для TUN. Он использует Windows Filtering Platform и удерживает блокировку при сбое процесса Mihomo, пока клиент открыт.

- Группы подписки раскрывают доступные серверы и маршруты прямо в списке. Вариант «Основной VPN» убран из редакторов маршрутов.

- Категории подписки поддерживают выбранные пользователем серверы и резервные группы. В категорию можно направить трафик по своему правилу.

- Вкладка **Группы** показывает категории из полной Mihomo-подписки. Для каждой категории можно выбрать назначение из подписки, основной VPN, прямой доступ или блокировку.
- Категории на открытой странице обновляются после синхронизации аккаунта и смены источника.
- Правила подписки, вложенные группы и наборы правил учитываются после пользовательских правил. Настройки категорий сохраняются в профиле маршрутизации.

- Обновлён экран маршрутизации. Правила показаны списком с поиском и видимым приоритетом, а группы и активные соединения вынесены на отдельные вкладки.

- Добавлен раздел **Маршрутизация** с правилами по EXE, доменам, IPv4/IPv6, подсетям, портам, GEOIP и GEOSITE. У правила можно выбрать TCP, UDP или оба протокола, изменить приоритет и отключить его.
- Добавлены отдельные маршруты для основного VPN, других серверов и групп с проверкой доступности, а также прямой доступ, блокировка и маршрут для остального трафика. Один процесс Mihomo может обслуживать несколько VPN-серверов одновременно.
- Профили можно создавать, импортировать и экспортировать в JSON. Изменения применяются к работающему ядру с проверкой и откатом при ошибке применения или записи.
- Добавлен монитор соединений Mihomo с созданием правил по приложению, домену, IP или порту.
- Локальный порт Mihomo принимает HTTP и SOCKS5. Добавлена блокировка UDP у VPN-маршрутов, серверы которых поддерживают только TCP. DNS назначения использует DoH через VPN.
- Добавлены интеграционные проверки с комплектным Mihomo для маршрутов, горячего применения, отката и блокировки обхода VPN.
